# Runtime schema contracts

Runtime schemas define deterministic, offline contracts with `additionalProperties: false`.

- **Collector contracts**: `collector/linux_inventory.schema.json`
- **Check contracts**: `check_result.schema.json`, `control_status.schema.json`
- **Evidence contracts**: `evidence_record.schema.json`
- **Report contracts**: `report_input.schema.json`
- **Export contracts**: `export_manifest.schema.json`
- **Shared contracts**: `common/metadata.schema.json`
